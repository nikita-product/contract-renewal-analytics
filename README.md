# Topface-Media

**Аналитика пролонгаций: отчёт по K1/K2 и визуализации для руководителя**

**О проекте**
Проект автоматизирует подготовку отчёта по продлениям договоров за 2023 год: очистка данных, расчёт K1 (продление в первый месяц) и K2 (продление во второй месяц), агрегаты по менеджерам и отделу, "чистые" таблицы и управленческие графики.

Состав репозитория

    notebook.ipynb — основной ноутбук: загрузка данных, очистка, расчёты K1/K2, визуализации, экспорт.

    financial_data.csv — помесячные суммы по клиентам/договором (сырые данные).

    prolongations.csv — метаданные пролонгаций: id, последний месяц, АМ, статусы ("стоп", "в ноль").

    requirements.txt — список зависимостей для воспроизводимого запуска.

Установка и запуск

    Установить зависимости одной командой:
    pip install -r requirements.txt

    Подготовка данных

    Поместите financial_data.csv и prolongations.csv в корень проекта 
    
    Откройте DataAnalyst.ipynb.

    Выполните ячейки последовательно.

Что делает ноутбук

    Нормализует названия месяцев (названия на русском -> YYYY-MM), парсит суммы с пробелами и запятой

    Исключает записи "стоп/end" до или в последний месяц, корректно обрабатывает "в ноль" с подстановкой из предыдущего месяца

    Считает K1/K2 на уровне id с корректной базой и числителем, сворачивает в агрегаты по АМ и отделу

    Формирует "чистые" матрицы: показываются только ячейки, где была реальная база
